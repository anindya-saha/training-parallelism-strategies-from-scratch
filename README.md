# Training Parallelism Strategies From Scratch

Hands-on implementations of distributed training parallelism strategies using native PyTorch.
Covers the full journey from transformer fundamentals to 5D parallelism, deployed via
 SageMaker HyperPod Job CRDs on Kubernetes.

## Project Structure


Each subfolder contains its own README with detailed documentation.

## Setup

```bash
uv sync
```

For development tools (black, isort, flake8):

```bash
uv sync --extra dev
```
